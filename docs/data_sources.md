# Исходные данные и приватность

## Использованные отчёты

Архивы `Systeme electric.zip` и `IEK.zip` содержат помесячные продажи за 2024–2026 годы, справочники MOQ, помесячные остатки и отчёты о товарах/заказах в пути. Для Systeme Electric используется свободный остаток из сводного отчёта на 22.09.2026. Для IEK используется остаток на начало сентября 2026 года; транзит суммируется по указанным в отчёте открытым заказам.

## Что сохраняет каталог

`data/demo_catalog.json` содержит поставщика, SKU 1С, артикул поставщика, краткое наименование, доступную категорию/единицу, MOQ, остаток, товары в пути, месячную историю и агрегированные количества исключённых крупных документов. Источником являются фактические выгрузки, а каталог — демонстрационный агрегат на 22.09.2026.

## Что не сохраняется

Скрипт не записывает номера накладных, номера документов, описания накладных, строки с клиентами и складские строки по отдельным операциям. Для поиска крупного документа он агрегирует отрицательные исходящие количества по SKU, документу и месяцу, затем сохраняет только объём исключённого спроса по SKU и месяцу.

## Ограничения полей

В выгрузках не найдено `client_id`, цены продажи и истории stockout. Отдельный журнал в пути не содержит срока поставки. В IEK нет явной категории товаров. Эти пропуски перечислены в интерфейсе и не выдаются за наблюдаемые факты.

Файл stockout загружается только в браузерный сценарий и передаётся локальному API для расчёта; сервер не сохраняет его. API по умолчанию слушает `127.0.0.1`. Для OpenAI уходит текст запроса и до 10 итоговых строк с SKU/наименованием, без номеров счетов или клиентских ID.
