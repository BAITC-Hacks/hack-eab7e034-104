# DEPLOY NOW — HackAlem demo

## Что увидит проверяющий

После публикации проверяющий открывает один публичный URL без регистрации.

1. На главной странице автоматически считается план пополнения.
2. Можно фильтровать по поставщику, категории, срочности и SKU.
3. Клик по строке показывает объяснение расчёта.
4. Поле «ЗАКАЗАТЬ» можно вручную изменить.
5. «Утвердить план» фиксирует подтверждённую версию в браузере менеджера.
6. «Экспорт CSV» выгружает черновик или утверждённый заказ.
7. «Что если?» меняет горизонт, спрос, остаток, товар в пути и stockout.
8. AI-агент отвечает через OpenAI, если задан OPENAI_API_KEY; без ключа работает локальный детерминированный demo-agent.
9. Автоматической отправки заказа поставщику нет.

## Локальный запуск

Windows:
```bat
python app.py
```

Открыть:
```
http://127.0.0.1:8000
```

Проверка:
```
http://127.0.0.1:8000/api/health
```

## Самый быстрый онлайн-деплой: Railway CLI

Из корня проекта:

```bat
npm install -g @railway/cli
railway login
railway init
railway up
railway domain
```

Команда `railway domain` выдаст публичный адрес вида `https://...up.railway.app`.

### Включить настоящий OpenAI-agent

В Railway Variables добавить:

```
OPENAI_API_KEY=<ваш ключ>
OPENAI_MODEL=gpt-5.6-luna
```

После изменения переменных Railway перезапустит приложение.

## 3-минутный сценарий для жюри

- Открыть публичный URL.
- Показать группировку по поставщикам.
- Выбрать категорию и открыть одну рекомендацию: показать прогноз, остаток, товар в пути, MOQ и объяснение.
- Изменить количество вручную и нажать «Утвердить план».
- Экспортировать CSV и показать статус «Утверждено менеджером».
- В «Что если?» увеличить спрос на 15% и пересчитать.
- В AI-агенте спросить: «Какие срочные позиции IEK на 30 дней и почему?»
- Показать раздел «Источники данных» и ограничения: отсутствующие client_id/stockout/lead-time не скрываются.

## Важно

Встроенный каталог собран из предоставленных выгрузок. Если правила хакатона или партнёра запрещают публичную публикацию этих агрегатов, разворачивать публично только разрешённую/синтетическую копию.
